# Bundled terminal font

JetBrains Mono **2.304**, regular and bold WOFF2 files, from
[JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono/tree/cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9).
Upstream commit: `cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9`.

The original filenames and font contents are unchanged. See [OFL.txt](OFL.txt)
for the SIL Open Font License and copyright. The preview serves these local
files and loads both weights before rendering; no font CDN is used.
